# Main Application Design System

This is the canonical reference for the application's visual identity. It defines the "warm editorial" atmosphere, the primary brand colors, and the specific typographic pairings that differentiate this product.

Detailed specifications for colors, typography, layout, and components can be found in the accompanying [README.md](README.md).

## Core Principles

- **Warm Editorial Canvas**: Tinted cream floor (`#faf9f5`), never pure white.
- **Brand Voltage**: Signature coral accent (`#cc785c`) used for primary actions and major callouts.
- **Editorial Typography**: Slab-serif display headlines (Copernicus) with negative tracking, paired with humanist sans body (Inter).
- **Product Mockup Depth**: Use dark navy surfaces (`#181715`) to showcase product chrome and code.
- **Generous Spacing**: 96px section rhythms and 32px internal card padding.

Refer to [README.md](README.md) for the full design token tables and component library.
